# AnonShare

Applicazione decentralizzata, senza server e a costo zero per lo **scambio bilaterale di file multimediali in tempo reale** (P2P e Tor).

## Istruzioni per la nuova sessione Antigravity

Quando apri una nuova chat di Antigravity in questo workspace, puoi semplicemente indicare:
> *"Leggi il piano architetturale approvato in `plan.md` e procedi all'implementazione della Fase 1 (Web App PWA in Modalità Diretta con signaling Nostr e Noise NNpsk0)."*

L'agente leggerà direttamente il file e avrà a disposizione l'intero contesto crittografico, di rete e di test senza trascinare la cronologia pregressa.
